# SowaLink 🔗📁 - Zero-Cloud E2EE Direct WiFi Peer-to-Peer Transfer

**SowaLink** is a modern, fast, and easy-to-use file transfer platform designed to make sharing files between devices simple and seamless.

Transfer photos, videos, documents, projects, ZIP files, and other files without relying on complicated setups. SowaLink focuses on providing a clean interface, smooth transfers, and a simple user experience.

## ✨ Features

* 🚀 **Fast File Transfer** - Transfer files quickly between connected devices.
* 📱 **Cross-Device Sharing** - Share files between smartphones, laptops, desktops, and other devices.
* 🔗 **Easy Device Connection** - Connect devices with a simple and intuitive process.
* 📂 **Multiple File Types** - Transfer photos, videos, documents, archives, and more.
* 📊 **Transfer Progress** - Monitor the progress of your file transfers.
* 🎨 **Modern Interface** - Clean, responsive, and easy-to-use UI.
* ⚡ **Simple & Lightweight** - Designed to keep file sharing straightforward and hassle-free.
* 🔒 **Privacy Focused** - Built with the goal of keeping personal file transfers private and secure.
* 🌐 **Browser-Based Experience** - Transfer files directly through a web interface without unnecessary software.

## 🎯 Why SowaLink?

Moving files between devices shouldn't feel complicated. Cables, cloud uploads, account requirements, and third-party storage can make a simple transfer unnecessarily difficult.

**SowaLink** aims to provide a smoother way to share files by focusing on three things:

**Speed • Simplicity • Privacy**

Select your files, connect your devices, and transfer them with minimal effort.

## 🚀 Getting Started

Clone the repository and install the required dependencies:

```bash
git clone <your-repository-url>
cd SowaLink
npm install
npm run dev
```

Open the local development URL in your browser and start transferring files.
